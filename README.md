# Customer Insight Power BI Dashboard

An interactive Business Intelligence solution that tracks customer value-engagement metrics, purchasing behaviors, and regional KPIs to support data-driven commercial decisions.

## Project Overview
This project focuses on transforming raw transactional data into an executive-facing Power BI dashboard. It enables stakeholders to dynamically filter metrics across regions, evaluate customer segment performance, and uncover purchasing trends.

## Tech Stack & Skills Demonstrated
* **Business Intelligence:** Power BI (DAX, Power Query, Data Modeling)
* **Database & Querying:** SQL (Relational schema structuring)
* **Analysis:** Exploratory Data Analysis, KPI tracking, stakeholder requirement translation

## Key Features & Impact
* **Relational Data Modeling:** Structured raw tables into clean, optimized star schemas to improve data refresh efficiency and reporting performance.
* **Dynamic Stakeholder Filtering:** Implemented dynamic slicers and page-level filters allowing management to segment data by region, customer demographic, and product category.
* **Commercial Metric Tracking:** Visualized customer lifetime value, engagement frequency, and purchasing patterns to highlight key revenue drivers.
